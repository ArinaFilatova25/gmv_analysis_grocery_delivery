# GMV Analysis | Grocery Delivery

### Анализ причин снижения оборота сервиса доставки продуктов

## О проекте

Проект посвящён исследованию причин снижения **GMV (Gross Merchandise Value)** сервиса доставки продуктов.

В апреле 2026 года GMV сократился на **24,2% относительно марта**.

**Цель проекта** — определить основные факторы падения оборота, проанализировать пользовательскую воронку, проверить статистическую значимость изменений и предложить рекомендации для бизнеса.

## Данные

Исследование выполнено на данных сервиса доставки продуктов за **ноябрь 2025 — апрель 2026 года**.

Используются три датасета:

| Датасет | Описание |
|---|---|
| `grocery_delivery_orders_2025_11_2026_04.csv` | Заказы, GMV, скидки, покупатели |
| `grocery_delivery_funnel_2025_11_2026_04.csv` | Пользовательские сессии и события воронки |
| `grocery_delivery_marketing_communications_2025_11_2026_04.csv` | Маркетинговые кампании и коммуникации |

## Этапы исследования

### 1. Подготовка и исследование данных

- Проверка пропусков, типов данных и корректности значений.
- Анализ структуры и качества данных.
- Агрегация показателей по месяцам.

### 2. Декомпозиция GMV

Использована формула:

**GMV = Количество заказов × Средний чек (AOV)**

Проанализирована динамика GMV, количества заказов, покупателей, среднего чека, трафика и конверсии.

### 3. Анализ пользовательской воронки

Исследованы переходы:

**Посещение → Поиск → Карточка товара → Добавление в корзину → Корзина → Покупка**

Рассчитаны конверсии между этапами и выявлены основные точки потери пользователей.

### 4. Сегментный анализ

Проведено сравнение показателей по:

- Платформам (Web, iOS, Android).
- Городам.
- Типам скидок.
- Источникам трафика.
- Маркетинговым коммуникациям.

### 5. Проверка статистических гипотез

Использованы:

- **ANOVA** и **Tukey HSD** — для анализа различий в долях скидок.
- **Z-test для двух долей** — для проверки изменений конверсий.
- **Поправка Холма** — для корректировки множественных сравнений.

## Основные результаты

| Метрика | Изменение в апреле |
|---|---:|
| **GMV** | **−24,2%** |
| Количество заказов | −21,2% |
| Количество покупателей | −15,7% |
| Конверсия из сессии в покупку | −15,1% |
| Количество сессий | −7,1% |
| Средний чек | −3,9% |

### Ключевые выводы

1. **Основной фактор снижения GMV — сокращение количества заказов**, а не среднего чека.

2. **Падение трафика не объясняет снижение оборота полностью.** Существенную роль сыграло ухудшение пользовательской конверсии.

3. Наиболее проблемный этап — **«Карточка товара → Добавление в корзину»**. Конверсия снизилась с **52,9% до 46,8% (−6,1 п.п.)**.

4. Статистические тесты подтвердили значимость снижения ключевых конверсий.

5. Падение GMV наблюдалось на всех платформах. Наиболее выраженное снижение зафиксировано на **Web (−29,5%)**, а также в **Новосибирске (−38,1%)** и **Казани (−33,3%)**.

6. Статистически значимых различий в средней доле скидок между месяцами не обнаружено (**ANOVA, p-value = 0,2945**).
