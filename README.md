# GMV Analysis | Grocery Delivery

## О проекте

Аналитический проект по исследованию динамики GMV (Gross Merchandise Value) сервиса доставки продуктов.

**Цель проекта:** выявить причины снижения GMV, определить ключевые факторы изменения выручки и предложить рекомендации для улучшения бизнес-показателей.

## Задачи исследования

- Проанализировать динамику GMV и количества заказов.
- Провести декомпозицию GMV на составляющие.
- Исследовать поведение пользователей на этапах воронки.
- Определить сегменты, влияющие на изменение GMV.
- Проверить статистические гипотезы.
- Сформулировать бизнес-рекомендации.

## Инструменты

- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- SciPy, Statsmodels
- Jupyter Notebook

## Методология

В рамках исследования проведены:

1. Подготовка и исследовательский анализ данных (EDA).
2. Анализ динамики ключевых бизнес-метрик.
3. Декомпозиция GMV.
4. Анализ пользовательской воронки.
5. Сегментный анализ.
6. Статистическая проверка гипотез.
7. Формирование выводов и рекомендаций.

## Данные

Использованы три набора данных сервиса доставки продуктов:

- Заказы пользователей.
- Пользовательская воронка.
- Маркетинговые коммуникации.

## Результаты

Исследование направлено на выявление основных факторов снижения GMV, оценку их вклада и поиск потенциальных точек роста.

Подробные расчёты, визуализации и выводы представлены в Jupyter Notebook.
